# Harness 检查清单

## 回答

- [ ] 直接回答当前问题，没有把工具过程当成答案。
- [ ] 关键事实有可靠依据；联网事实使用当前来源。
- [ ] 推断、未核验信息和不确定性已明确标注。
- [ ] 检查强度与风险匹配，通过后停止。

## 知识解释

- [ ] 已加载与主题、触发语匹配的教学 Skill，并把其中步骤作为验收门而非可选风格。
- [ ] 对陌生概念先从最小具体载体开始；“已经阅读或看过一遍”没有被当作可以跳过底层步骤的理解证据。
- [ ] 明确每个关键量是原始样本、像素、滤波器权重、响应、频率坐标、变换系数、幅度、相位还是其他对象，并说明所在域与必要单位或形状。
- [ ] 至少完整算完一个能展示核心机制的例子，而不是只给一个未展开的标量等式。
- [ ] 至少给出一个数值对照或反例，并解释正、负、零、大小、方向或相位在当前问题中的实际含义。
- [ ] 陌生公式已逐符号、逐关键等号展开，并说明公式能回答和不能回答什么。
- [ ] 已给出因果链、`必须掌握`、`暂时了解即可` 与迁移式自测；内容过长时分模块，不通过删掉必要步骤压缩。
- [ ] 没有把“内容已覆盖”误报为“用户已掌握”或擅自同步完成状态。

## 文献与知识产物

- [ ] DOI、citekey、页码、图表、公式和数值没有猜测。
- [ ] 作者结论、原文证据、AI 解释、用户判断和开放问题已区分。
- [ ] Markdown 状态为 `ai-draft`，正式晋升已有用户批准。
- [ ] `html_artifact` 存在，HTML `paired_note` 回链正确，局部资源存在。
- [ ] HTML 标明来源、生成日期和 AI/核验状态。

## 文件与配置

- [ ] 写入路径属于本任务获准的控制表面。
- [ ] JSON/JSONL 可逐条解析；YAML frontmatter 可解析且类型正确。
- [ ] 移动/删除前已检查反向链接、嵌入、Canvas 和 Base，并列精确清单。
- [ ] 配置变更后已断言实际字段，而不是只凭文件看起来正确。
- [ ] 长任务的 `verification.md` 保存了新鲜命令、退出码和结果摘要。

## 结束

- [ ] 完成条件逐项有证据。
- [ ] 只剩外部阻塞时已说明阻塞和下一步。
- [ ] 没有为了固定次数而重复已经通过的检查。
